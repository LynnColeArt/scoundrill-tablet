# Attribution and reference

The pressure implementation is a source-informed reconstruction of
[Krita 6.0.5](https://github.com/KDE/krita/tree/1706bc8e0469b330017001fe9ddf89ddbfe15950).
See [the upstream manifest](reference/upstream.json) for the exact commit and
SHA-256 hashes. The Krita curve sources credit C. Boemann, Dmitry Kazakov, Cyrille
Berger and Deif Lou. The pressure implementation is distributed under
[GPL-2.0-or-later](LICENSE).

The reference executable compiles the unchanged `KisCubicCurve` and
`KisCubicSpline` sources. It calls `floatTransfer(1025)` and
`interpolateLinear`, mirroring the lookup table and interpolation in
`KisPaintingInformationBuilder`. The headless adapter adds JSON validation and
integer rounding for reproducible comparison. Its include shims supply a
substitute for Krita's assertion and export infrastructure and supply the
original sign convention. The original string parser and canvas event paths
are outside the adapter.

The Zig curve solves the same natural spline in local coordinates using a
tridiagonal system. Krita uses Eigen to solve for global polynomial
coefficients. Their floating-point evaluations can differ, and the gate checks
the rounded output for the recorded corpus. An additional comparison across
8,000 generated samples measured a maximum difference of five billionths.

[Ziggify](https://github.com/LynnColeArt/ziggify/tree/58ed6a7ecc45aa0af1ab886cab916fa6f1167bd4)
0.2.0-alpha.1. Their MIT license is included in [LICENSE-ZIGGIFY](LICENSE-ZIGGIFY).
